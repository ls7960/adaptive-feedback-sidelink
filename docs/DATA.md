# Data interfaces

`data/benchmark/manifest.json` lists 120 public synthetic **test** inputs. Each
scenario is a strict `EvaluatorScenario` JSON object. We extracted only the
`scenario` object from each archived public artifact; historical paths and
generation certificates were not copied. Each entry retains the original public
artifact hash and scientific fingerprint, plus the hash of the public file. Scenario identifiers were replaced with
`easy-001` through `hard-040`; all other scenario values were checked unchanged.
No private anchor or method score is present in an input scene.

The frozen benchmark has 40 easy, 40 medium and 40 hard instances with 24/28/32
nodes and 14/16/18 flows respectively. Dataset parsing checks hashes, membership,
path containment, identity uniqueness and the domain schema. It does not rerun
scenario generation, GA, RL or an LLM.

To use the public trainer, supply your own independent datasets with the same
manifest structure, using `split: train` and `split: validation`. Paths must stay
inside the manifest directory. The required manifest fields are:

```json
{
  "schema": "sidelink-public-benchmark-v1",
  "split": "train",
  "count": 1,
  "entries": [
    {
      "scenario_id": "your-unique-scenario-id",
      "path": "scenarios/your-scene.json",
      "sha256": "replace-with-the-64-character-sha256-of-the-file"
    }
  ]
}
```

Renaming the same scenario does not create independent validation data: the
trainer also compares a hash of scenario content excluding its identifier.
The included benchmark is a test set and cannot be passed directly to training.
The explicit single-source exception, `--source-only`, requires the same one-scene
`train` manifest for both arguments and is supported only with the full policy.
It records source-based checkpoint selection in the run summary.

`data/published/statistics.json` contains numerical aggregates and the
original statistical source hash. `llm_metrics.json` preserves the 360 per-scene
repeat observations without checkpoint paths. `iteration120.csv` is copied from
the paper figure's frozen input. These are existing observations, not generated by
the example scripts. Published values and source tests are covered by the MIT
license in this release; no third-party manuscript class or publisher figure is
redistributed.
